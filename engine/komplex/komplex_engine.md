# Komplex Engine

(_Komplex_, `complex` in swedish... Or german.... Depends...)

**Rust Based** Engine for Milk Toast Taco, with **Lua** for Game scripting.

## Cool Rust Libraries i should remember: (Not neccisarly just for Komplex)

- [inquire](https://github.com/mikaelmello/inquire) (Terminal Prompts)
- [starship](https://starship.rs/) (Unknown)
- [AppCUI-rs](https://github.com/gdt050579/AppCUI-rs) (TUI interfaces)
- [wgpu](https://wgpu.rs/) (Graphics and Rendering)
- [gltf](https://github.com/gltf-rs/gltf) (3D asset loader)
- [ash](https://github.com/ash-rs/ash) (Vulkan bindings for Rust)
